# Meu segundo cérebro

| Pasta | Para que serve |
|---|---|
| 00-entrada | Caixa de chegada: ideias e coisas para organizar depois |
| 01-projetos | Projetos com começo e fim, uma nota por projeto |
| 02-areas | Responsabilidades contínuas: consultório, carreira, pesquisa. Aqui fica a nota [[Quem sou eu]] |
| 03-referencias | Conteúdo para consulta: resumos de artigos, guias, contatos |
| 04-arquivo | O que terminou ou parou |
| diario | Uma nota por dia com o que mudou |

O [[Índice]] lista todas as notas.

## Como o Claude Code usa
- **Antes** de uma tarefa nova, ele procura aqui o que já existe sobre o assunto e lê a nota Quem sou eu.
- **Depois** de uma entrega importante, ele registra o que foi decidido e por quê, e anota no diário do dia.
- Quem ensina isso a ele é a skill `segundo-cerebro` e o bloco de regras no CLAUDE.md global.
