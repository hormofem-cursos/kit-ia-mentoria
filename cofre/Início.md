**Como o seu segundo cérebro funciona e onde fica cada coisa.**

# Início

## As pastas

| Pasta | Quem escreve | O que vai nela |
|---|---|---|
| [[Quem sou eu]] | você | Seu perfil, projetos e jeito de trabalhar. O Claude lê antes de toda tarefa |
| `notas/` | o Claude | Uma nota por assunto: projetos, decisões, preferências, erros a evitar, padrões, pessoas |
| `diario/` | o Claude | Uma nota por dia com o que mudou, decidiu e ficou em aberto |
| `fontes/` | o Claude, a seu pedido | Resumos de artigos, livros, aulas e cursos, sempre com a origem |
| `pessoal/` | você | Suas anotações. O Claude só mexe aqui quando você pede |
| `modelos/` | ninguém | Modelos de nota |

O [[Índice]] lista todas as notas e é refeito sozinho.

## O que acontece sem você pedir

1. **Ao abrir o Claude Code**, ele recebe um lembrete de que este cofre existe e vê os últimos registros do diário.
2. **A cada pedido seu**, o cofre é pesquisado com as palavras do pedido, e as notas relacionadas vão junto para o Claude.
3. **Ao fim de uma sessão com trabalho de verdade**, se nada foi registrado, ele pede para registrar uma vez.
4. **Em segundo plano**, o índice é refeito, um exame de saúde roda toda semana e, se o cofre estiver no GitHub, ele é salvo a cada 30 minutos.

## Os tipos de nota

| Tipo | Quando usar | Exemplo |
|---|---|---|
| projeto | Tem começo e fim | Curso on-line de climatério |
| decisao | Algo foi decidido, com o porquê | Atendimento só particular a partir de 2027 |
| preferencia | Um jeito seu de querer as coisas | Textos curtos, sem jargão para pacientes |
| armadilha | Erro que não pode se repetir | O plugin X apagou a agenda |
| padrao | Um jeito de fazer que deu certo | Roteiro de vídeo em 3 partes |
| pessoa | Alguém com quem você trabalha | Secretária, sócio, fornecedor |
| area | Responsabilidade contínua | Consultório, pesquisa, carreira |
| referencia | Onde mora cada coisa | Contas, sites, pastas (nunca senha) |

No Obsidian, cada tipo aparece com uma cor na visão em grafo.

## Pedidos úteis

- "Procure no meu segundo cérebro o que eu já tenho sobre ___."
- "Registre essa decisão, com o porquê."
- "Anote no diário de hoje o que avançamos."
- "Faça a faxina do meu segundo cérebro." (roda o exame de saúde e corrige)
- "Salve o meu segundo cérebro no GitHub agora."

## Regra de ouro

Nenhum dado que identifique paciente, nenhuma senha e nenhuma chave entram aqui.
